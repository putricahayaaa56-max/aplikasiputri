# Tugas 1 - Merancang Antarmuka (UI) Dasar Aplikasi Mobile

Aplikasi Belajar Mengenal karakter seseorang berbasis Android yang dikembangkan menggunakan Kotlin dan XML di Android Studio.
Aplikasi Android Saya

Aplikasi Android yang dibuat menggunakan Kotlin dan Jetpack Compose.

Fitur Aplikasi

- Tampilan antarmuka aplikasi Android.
- Navigasi antarhalaman.
- Fitur sesuai dengan fungsi aplikasi yang dibuat.

Teknologi yang Digunakan

- Kotlin
- Android Studio
- Jetpack Compose

Cara Menjalankan Aplikasi

1. Download atau clone repository ini.
2. Buka project menggunakan Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Jalankan aplikasi menggunakan emulator atau HP Android.
